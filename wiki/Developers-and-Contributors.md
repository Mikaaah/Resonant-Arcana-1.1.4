# Contributors

Read the [development notes](https://github.com/Mikaaah/Resonant-Arcana-1.1.4/blob/main/docs/DEVELOPMENT.md) and [repository guidance](https://github.com/Mikaaah/Resonant-Arcana-1.1.4/blob/main/AGENTS.md) before changing the mod. The build uses the current source overlay and preserved 1.1.3 baseline. Do not replace current behavior with historical source.

Java 21 / Minecraft 1.21.1 / NeoForge. Build with `./gradlew clean visibilityChecks jar`. Runtime checks require the dependencies in [verification reports](https://github.com/Mikaaah/Resonant-Arcana-1.1.4/tree/main/verification/1.1.4).
